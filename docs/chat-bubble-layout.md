# 对话气泡空白修复（2026-09-15）

## 原因与行为

此前为解决宽表格溢出，将用户和助手消息的父容器同时改成 `flex-1`，内部块级气泡随之撑满整行。工具状态卡片还通过 `ml-auto` 把状态推到最右侧，形成大段空白。

- 用户消息使用内容宽度，靠右排列，达到当前对话框的可用宽度后换行。
- 助手内容列保留完整可用宽度以容纳结果卡片；文字气泡和工具状态卡片分别使用 `w-fit max-w-full`。短消息不会被同一回合的宽结果卡撑开。
- Markdown 表格和代码块通过 `has-[table]:w-full` / `has-[pre]:w-full` 使用可用宽度，保留换行、防溢出与滚动处理。
- 工具名称与状态使用固定间距，移除自动外边距；图标不压缩，长状态文字自动换行。
- 新对话、流式回复和恢复历史会话使用相同消息组件。

类型检查、76 项现有前端测试与生产构建通过。浏览器使用生产 JS/CSS，仅在独立浏览器上下文中回放身份、历史会话和 SSE 数据，不调用模型或写入真实用户数据。
